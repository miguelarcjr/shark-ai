# subagent-driven-development-lite Improvements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement dynamic report file naming linked to subagent IDs, add hybrid recovery fallback (Dual-Write) in the orchestrator scripts, and enhance subagent prompts to ensure robust execution under shark dev.

**Architecture:** Update prepare-brief.mjs to query subagents.json to find the latest subagent IDs for Implementer and Reviewer, resolving paths as `task-subagent-[ID]-report.md` or `task-subagent-[ID]-review-report.md`. If a report is missing, extract it directly from the JSON. Refactor prompt templates to explicitly instruct and guide subagents in calling file-writing tools.

**Tech Stack:** Node.js, JavaScript, Git.

## Global Constraints

- Every report generated by a subagent must have a unique filename containing the subagent's execution ID.
- If a report is missing on disk, prepare-brief.mjs must recover it from .shark/subagents.json before launching the next subagent.
- Subagents must not use shell commands (like mkdir, echo, cat) to create directories or files.
- All code changes must live in the bmadspot workspace under `skills/subagent-driven-development-lite`.

With recovery setup:
```javascript
    // Helper to find the latest subagent report content
    function getLatestSubagentReportContent(role) {
        const subagentsFile = path.resolve('.shark', 'subagents.json');
        if (!fs.existsSync(subagentsFile)) return null;
        try {
            const data = JSON.parse(fs.readFileSync(subagentsFile, 'utf8'));
            let latestTime = 0;
            let content = null;
            let subagentId = null;
            for (const id in data.subagents) {
                const sa = data.subagents[id];
                if (sa.role === role && sa.status === 'completed' && sa.endedAt > latestTime) {
                    const saContent = sa.lastAction?.params?.content;
                    if (saContent) {
                        content = saContent;
                        latestTime = sa.endedAt;
                        subagentId = id;
                    }
                }
            }
            return { content, subagentId };
        } catch {
            return null;
        }
    }

    // Dynamic resolution of Implementer report path
    let implementerReportFile = path.join(sddDir, `task-${taskNum}-report.md`);
    const latestImplementer = getLatestSubagentReportContent('Implementer') || getLatestSubagentReportContent('Fixer');
    if (latestImplementer && latestImplementer.subagentId) {
        implementerReportFile = path.join(sddDir, `task-subagent-${latestImplementer.subagentId}-report.md`);
        if (!fs.existsSync(implementerReportFile) && latestImplementer.content) {
            fs.writeFileSync(implementerReportFile, latestImplementer.content, 'utf8');
            console.log(`RECOVERED: Wrote missing report for ${latestImplementer.subagentId} to ${implementerReportFile}`);
        }
    }
```
