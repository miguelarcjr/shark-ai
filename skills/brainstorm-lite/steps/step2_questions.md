# Step 2/7: Clarifying Questions

## Goal
Clarify goals, constraints, and success criteria.

## Actions
1. Ask the user 1 or 2 simple, direct questions about their request.
2. Keep questions concise. Prefer multiple choice options.
3. Keep the state block in the design file as:
   ```markdown
   <!-- BRAINSTORM STATE
   - [x] 1/7 Explore Context
   - [/] 2/7 Clarifying Questions
   - [ ] 3/7 Propose Approaches
   - [ ] 4/7 Present Design
   - [ ] 5/7 Write Design Doc
   - [ ] 6/7 Review & Approve
   - [ ] 7/7 Transition to Plan
   -->
   ```
4. Wait for the user's response. Do not transition to Step 3 until the user replies.

---

**Next Step:** Once the user has replied to your questions:
1. Update the state block in the spec file to mark Step 2 as `[x]` and Step 3 as `[/]`.
2. Read and follow the instructions in [step3_approaches.md](step3_approaches.md).
