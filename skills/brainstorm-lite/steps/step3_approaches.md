# Step 3/7: Propose Approaches

## Goal
Propose exactly 2 different approaches to solve the problem and get user feedback.

## Actions
1. Update the state block in the design file to:
   ```markdown
   <!-- BRAINSTORM STATE
   - [x] 1/7 Explore Context
   - [x] 2/7 Clarifying Questions
   - [/] 3/7 Propose Approaches
   - [ ] 4/7 Present Design
   - [ ] 5/7 Write Design Doc
   - [ ] 6/7 Review & Approve
   - [ ] 7/7 Transition to Plan
   -->
   ```
2. Propose exactly 2 approaches with trade-offs (2 pros, 2 cons each).
3. Recommend one approach and explain why.
4. Ask the user: "Which approach do you prefer?" and wait for their response.

---

**Next Step:** Once the user chooses an approach:
1. Update the state block in the spec file to mark Step 3 as `[x]` and Step 4 as `[/]`.
2. Read and follow the instructions in [step4_design.md](step4_design.md).
